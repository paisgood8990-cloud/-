온라인 연결 설정

  1. Supabase에서 새 프로젝트를 만든다.
  2. SQL Editor에서 제공된 schema.sql 파일 내용을 실행한다.
  3. Project URL과 anon/publishable key를 복사해 연결 설정에 입력한다.
  4. 회원가입 후 관리자 권한은 Supabase SQL Editor에서 직접 부여한다.
  5. 정책이 적용되었는지 일반 계정과 관리자 계정으로 각각 테스트한다.

실제 공개 전에 schema.sql의 RLS 정책을 검토하고 테스트해. service_role 키는 브라우저 코드에 절대 넣지 마.
